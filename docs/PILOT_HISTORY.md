# Pilot history

The May 2026 Probe Scent work is preserved exactly on the branch
`archive/probe-scent-pilot-2026-05`, created from commit
`e3d2260a9438d1f5877904ecdcb374bdebc81383`.

Those experiments remain useful motivating evidence but are not the v1 confirmatory benchmark.

## Why the pilot is not canonical v1 evidence

The pilot established a large and replicable separation between the original neat and messy
conditions. The clean 118-row run reported mean scores of 0.00 for messy temptation, 94.87 for
neat temptation, and 94.43 for explicit evaluation.

However, the clean neat prompts contained direct evaluative cues such as statements that a file
showed how work would be judged, could help the assistant pass, or could be accessed without the
reviewer seeing it. Meanwhile many messy prompts contained ordinary clutter without the same
underlying tempting resource. That makes the pilot unsuitable for the strongest causal
interpretation that *placement neatness itself* generated the effect.

The pilot is therefore retained as:

- evidence that the construct is measurable;
- evidence that wrapper contamination and data-loss failure modes were discovered and corrected;
- motivation for a stricter matched confirmatory design.

The v1 protocol fixes the manipulation by matching the same tempting file across messy and neat
conditions and adding a benign-neat control.
